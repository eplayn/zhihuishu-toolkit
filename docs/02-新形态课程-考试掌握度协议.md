> 补充文档 —— 针对**有掌握度要求**的课程（如「大学物理(A)II-2026秋冬」）。

> 与 `新形态课程协议分析.md` 配套：那篇讲学习进度，这篇讲**考试与掌握度**。

## 一、两套系统的差别

「复变函数B」只有**学习进度**（`studyProgress`），刷完 `completed` 就到 100%。
「大学物理(A)II」额外有**掌握度**（`masteryPercentage`），必须**做测验**才能拉起来。

```
知识点
  ├─ studyProgress     学习进度   ← completed 驱动
  └─ masteryPercentage 掌握度     ← 考试分数驱动
```

`get-node-master-max` 返回该知识点的**掌握度上限**（例：`{"masteryMax": 77}`）。

## 三、完整考试流程（实测）

```
① POST /gateway/t/v1/exam/user/openExam
   {"examTestId":3362317,"examPaperId":412259413,"courseId":"20000002"}

② GET  /gateway/t/v1/exam/user/getExamTestUserInfo
   → {"examTestId","examPaperId","examState":3,"examType":5,
      "questionCount":6,"limitTime":0,"isObjective":true,...}

③ GET  /gateway/t/v1/exam/user/getExamSheetInfo
   → partSheetVos[].questionSheetVos[]  （答题卡，拿到全部 questionId）

④ GET  /gateway/t/v1/question/getExamQuestionInfo?questionId=...
   → 题目内容 + 选项
   ⚠️ 此时 optionVos[].isCorrect 全为 null（不给答案）

⑤ POST /gateway/t/v1/exam/user/updateUserUsedTime   每 5 秒
   {"examTestId":"3362317","examPaperId":"412259413","heartbeatTime":5}

⑥ POST /gateway/t/v1/answer/saveAnswer   逐题保存
   {"recruitId":"20000002","examTestId":"3362317",
    "examPaperId":412259413,"questionId":949218156,"dataVos":null,
    "answer":"705133432#@#705133433#@#705133434#@#705133435#@#705133436"}

⑦ POST /gateway/t/v1/exam/user/submit
   {"examTestId":"3362317","courseId":"20000002",
    "courseType":8,"examPaperId":"412259413",
    "aiKnlowledgeId":"1807608410561187840"}
   → {"score":0.00,"isLookAnswer":1,...}
```

### 3.1 `answer` 字段格式（重要）

| 题型 | `questionType` | `answer` 格式 |
|---|---|---|
| 单选 | 1 | 直接是 optionId，如 `705133396` |
| 多选 | 2 | optionId 用 **`#@#`** 连接，如 `705133432#@#705133433` |
| 判断 | 14 | 同单选，optionId（"对"/"错"各自的 id） |

## 四、★ 答案收割（核心）

### 4.1 交卷后题目会带答案

`submit` 响应里 `isLookAnswer: 1` —— **允许查看答案**。

交卷后重新调用接口，**`isCorrect` 会被填上**：

```json
{
  "id": 949218156,
  "content": "关于库仑定律，以下哪些描述是正确的？",
  "result": "A,B,C,D",                      ← 答案字母
  "userAnswerVo": [{"answer":"705133432#@#...","isCorrect":0}],
  "analysisVo": {"analyze": "库仑定律描述了...(A)...（E错误）。"},
  "optionVos": [
    {"id":705133432,"content":"...","isCorrect":1},   ← ★ 正确答案
    {"id":705133436,"content":"...","isCorrect":0}
  ]
}
```

同时 `getExamSheetInfo` 的 `correct` 字段变成 `0/1`（每题对错）。

### 4.2 收割流程

```
第一遍（乱答）：
  openExam → getExamSheetInfo → 逐题 getExamQuestionInfo
  → saveAnswer（随便填）→ submit

第二遍（收割）：
  重新 getExamSheetInfo / getExamQuestionInfo
  → 收集「questionId → 正确 optionId 列表」

第三遍（满分）：
  重开一份卷（paperId 会变）→ 用查表答案 saveAnswer → submit
```

**题库稳定** —— 第二轮起直接查表，可一次满分。

## 五、另一个带答案的接口（练习）

`kg-ai-run` 上还有一个练习接口，**不交卷就直接给答案**：

```http
POST /run/gateway/t/stu/mastery-statistics/get-test-question
{"courseId":"...","classId":"...","knowledgeId":"...",
 "examTestId":3362317,"paperId":412263825}
```

响应：

```json
{"questionList":[{
  "id":"939343668",
  "content":"<p>静电场是有源无旋场（ ）</p>",
  "optionVos":[{"id":672082792,"content":"对","isCorrect":1},
               {"id":672082793,"content":"错","isCorrect":0}]}]}
```

**注意：一次只返回 1 道题**，且在 2 道之间轮换（不是整份卷子）。
适合快速拿几个答案，不能替代上面的收割流程。

## 六、掌握度相关接口

| 接口 | 作用 |
|---|---|
| `/run/gateway/t/stu/mastery-statistics/get-node-master-max` | 掌握度上限 → `{"masteryMax":77}` |
| `/run/gateway/t/stu/mastery-statistics/get-knowledge-mastery-stat` | 知识点掌握统计 |
| `/run/gateway/t/stu/mastery-statistics/mastery-levels-list` | 掌握度等级表 |
| `/run/gateway/t/stu/maptree/get-graph-map-tree-with-mastery` | 带掌握度的图谱树 |
| `/run/gateway/t/stu/ability/query_ability_student_detail-v2` | 能力/掌握度总览（含 `avgScoreRate`） |
| `/course/gateway/t/v1/course/query-course-ability` | 课程能力配置 |

`query_ability_student_detail-v2` 响应字段：

```
avgScoreRate, abilityAllList[].{score, scoreRate, masteryScore,
  masteryScoreRate, taskScore, examScore, ...}
```
