## 一、登录态

### 1.1 登录链路（实测 302 链）

```
login.zhihuishu.com/?origin=zhs                          ← 登录中心（Vue SPA）
   → POST user.zhihuishu.com/zhsuser/login/account        （AES 加密的账密/扫码）
   → GET  user.zhihuishu.com/zhsuser/certify/queryCertify/{uuid}
   → GET  passport.zhihuishu.com/login
             ?pwd=<一次性密码>
             &service=https://cloudapi.polymas.com/oauth/login/ssoLogin?redirect=...
   → 302  ticket=ST-6385731-...-passport.zhihuishu.com
   → GET  cloudapi.polymas.com/oauth/login/ssoLogin?ticket=...
             ★ 在此下发 CASLOGC / CASTGC / jt-cas / polymas-token
   → 302  www.zhihuishu.com/
   → 各子系统再各自换票：
        onlineservice-api.zhihuishu.com/gateway/f/v1/login/gologin?fromurl=...
        cloudapi.polymas.com/oauth/login/ssoLogin?redirect=hike-teaching-center.polymas.com/...
```

**二维码登录链路仍然可用**（依赖第 4 步的 `pwd=` 一次性密码机制）。

### 1.2 CASLOGC —— 核心凭据

URL 编码的 JSON，**8 个字段**：

```json
{"realName":"…","myuniRole":0,"myinstRole":0,"userId":1000001,
 "headPic":"…","uuid":"AbCd1234","mycuRole":0,"username":"be1d6f0a…"}
```

- `uuid` 是后续大量接口的 `?uuid=` 参数
- 前端 `getMainCode()` = `JSON.parse(localStorage.CASLOGC).uuid + "zhs"`
- **CASLOGC 由 `cloudapi.polymas.com` 的 CAS ssoLogin 下发，不是 passport**

### 1.3 Cookie 全景（studyservice-api 实测 10 个）

```
locale, CASTGC, CASLOGC, jt-cas, Hm_lvt_…, HMACCOUNT,
exitRecod_AbCd1234, Hm_lpvt_…, acw_tc, SERVERID
```

四层：CAS 票据 / 业务身份 / 会话（JSESSIONID、SESSION）/ 风控路由（SERVERID、acw_tc、INGRESSCOOKIE）

**单点登录**：别处登录 → 现有 cookie 立即失效。

### 请求封装

```
POST https://studyservice-api.zhihuishu.com/gateway/t/v1<path>
Content-Type: application/x-www-form-urlencoded
Origin/Referer: https://studyh5.zhihuishu.com

body: secretStr=<AES(json).base64>&dateFormate=<ms>
```

- `dateFormate` **出现两次**：加密体内一份 + 表单外层明文一份
- 取值 = `Math.floor(Date.now()/1000) * 1000`（**恒以 000 结尾**）
- 成功判定：`code === 0`（注意不是 HTTP 状态码）

### ev 编码器（`D26666`）

```js
KEY = "zzpttjd"
Z(arr) = X(arr.join(';'))
X(str) = 每字符 (charCodeAt(i) XOR KEY[i % KEY.length]) → toString(16) → 不足2位补'0' → slice(-4) → 拼接
```

## 四、进度上报（核心）

### 4.1 上报节奏（源码 `startTotalTimer`）

```js
learningTimeRecordInterval = setInterval(learningTimeRecord,  1990)    // watchPoint 累加
totalStudyTimeInterval     = setInterval(totalStudyTimeFun,   4990)    // 学习时长心跳
cacheInterval              = setInterval(svcpEveryOnceInAWhile, 180000) // 缓存上报 3 分钟
databaseInterval           = setInterval(saveDdsjkTimeInWhileFn, 300000) // 主上报 5 分钟
```

### 4.2 watchPoint（`ewssw`）

```js
// 每 1990ms 执行
val = parseInt(totalStudyTime / 5) + 2
watchPointPost = (watchPointPost == '' ? "0,1," : watchPointPost + ',') + val
```

### 4.3 学习时长心跳（每 4990ms）

```js
totalStudyTime += 5 * playRate
totalTimeFinish += 5 * playRate
playTimes      += 5 * playRate
computeProgree()      // percentage = totalStudyTime / videoSec * 100
```

- `playRate` 前端被硬钳在 **1.8x**
- **完成阈值：`percentage >= 81`（0x51）→ isStudiedLesson = 1**

### 4.4 `sdsew` 的数组（**10 元素**，顺序即语义）

```js
[
  this.recruitId,                     // 0
  this.lessonId,                      // 1
  this.smallLessonId,                 // 2
  this.lastViewVideoId,               // 3
  this.videoDetail.chapterId,         // 4
  this.data.studyStatus,              // 5
  parseInt(this.playTimes),           // 6
  parseInt(this.totalStudyTime),      // 7
  round(player.getPosition()),        // 8  ← 播放器实时位置
  this.getMainCode()                  // 9  = uuid + "zhs"
]
```

### 4.5 上报条件（`saveDdsjkTimeInWhileFn`）

```js
if (isSaving) return;
if (playTimes <= 5 && !force) {
    totalStudyTime -= playTimes;   // 回退，不报
    playTimes = 0;
} else {
    // 构造并提交
}
```

- 定时器每 5 分钟无参调用 → `playTimes > 5` 才真正上报
- 切换视频时以 `type=4, force=true` 强制冲刷

## 五、习惯分

```js
'habitWarn': function() {
  if (!hasHabbitScore || isHabitTime) return;
  habitTime = localStorage.getItem("habitTimeKey") || 0;
  habitTimer = setInterval(() => {
    habitTime++;
    if (habitTime == 1500) {                       // 25 分钟
      currentSystemTime({}).then(r => {
        if (r.code == 0) localStorage.setItem("isHabitTime", "true" + r.data);
      });
      clearInterval(habitTimer);
      lookHabitDialog = true;
      player.pause();
    }
  }, 1000);
}
```

**结论**：习惯分 = **单日单页累计停留 1500 秒（25 分钟）**，用服务器时间戳（`/learning/currentSystemTime`）打标，localStorage 键 `habitTimeKey` / `isHabitTime`。

## 六、服务端错误码

| code | 含义 | 前端行为 |
|---|---|---|
| `0` | 成功 | — |
| `-9` | 学习时间已结束 | 提示「观看视频将不再计进度」 |
| `-10` | **多开播放** | 提示「同时播放多个视频…进度将停止记录」 |
| `-12` | 易盾验证码 | 弹出滑块 |
| `403` | 登录过期 | 跳 `gologin?fromurl=` 重新登录 |
| `422` | 参数/状态异常 | 暂停播放器 |
