## ★ 请求必须是 form-urlencoded

```
Content-Type: application/x-www-form-urlencoded
body: secretStr=<urlencode(b64)>&date=<epoch_ms>
```

**用 `application/json` 会报：**
```
{"code":400,"message":"java.lang.RuntimeException: aes加密参数异常
  com.zhihuishu.starter.secret.service.AesAbstractService.checkDecryptParam(...)"}
```

响应是明文 JSON，成功判定看 `code == 200`。

## 3. 其它课程入口（备用）

```
GET  /gateway/t/v1/student/course/share/querySelectCourseInfo    已选课程（马原返回空）
POST /gateway/t/v1/student/course/share/queryMicroCourseInfo     微专业课
GET  /gateway/t/v1/student/getStudentNoCommitExam                未提交考试
GET  /gateway/t/v1/student/home/index/getServerTime              服务器时间

hike-teaching-api.zhihuishu.com/gateway/t/v1/student/online/course/getCourseList
   → 返回的是【教师角色】的课（teacherRole: true），不是学生课表

b2cpush.zhihuishu.com/b2cpush/courseDetail/query2CCourseList
   → 2C 课程，普通学生为空

school-platform.zhihuishu.com/spCourse/queryStudentSchoolCourseList
   → 校平台课程，本次为空
```

## 字段 → 工具参数对照

| 来源字段 | 用于 |
|---|---|
| `courseId` + `classId` | 工具 01 / 02（新形态课程） |
| `recruitId` + `courseId` + `schoolId` | 工具 03 / 04 / 05（共享课） |

# 附：登录链路（实测时序）

```
① GET  onlineservice-api.../login/getLoginUserInfo
       → {"code":403,"message":"未登录"}        未登录时的基准

② GET  passport.zhihuishu.com/login              登录页
③ GET  passport.zhihuishu.com/user/imageCaptcha  图形验证码
④ GET  c.dun.163.com/api/v2/getconf              网易易盾初始化（风控）
⑤ POST user.zhihuishu.com/zhsuser/login/account  ★ 账号密码登录
       → {"status":1,"rt":{"uuid":"<uid>","pwd":"<md5>"}}
       ★ 返回的 pwd 是后续 SSO 换票凭据
⑥ GET  cloudapi.polymas.com/oauth/login/ssoLogin SSO 换票
⑦ GET  onlineservice-api.../login/gologin        建立学生会话
⑧ GET  onlineservice-api.../login/getLoginUserInfo
       → {"result":{"realName":"...","uuid":"<8位>","username":"<md5>"},"code":200}
```

**验证会话是否有效**：
```powershell
python tools\00_课程总览.py     # 能列出课程 = 会话有效
```

# 附：几个「状态自查」接口

登录后首页会调这批，都是只读的，可以用来判断账号是否干净：

| 接口 | 正常返回 |
|---|---|
| `student/getStudentNoCommitExam` | `{"data":[]}` 无未提交考试 |
| `student/home/index/getCertificateInfo` | `{"schoolId":1,"status":1}` |
| `mirror/home/cheat/findExamCheatListCount` | `0` 考试异常记录 |
| `mirror/home/cheat/findAbnormalCount` | `0` 异常总数 |
| `student/course/share/queryMicroCourseInfo` | `totalCount: 0` |
| `student/course/share/querySelectCourseInfo` | `[]` |
| `b2cpush.../query2CCourseList` | `size: 0` |

> ⚠️ `mirror/home/cheat/*` 这几个是**风控异常计数**。
> 跑自动化脚本被判定异常时这里会涨 —— 时不时看一眼，别把自己跑进黑名单。
